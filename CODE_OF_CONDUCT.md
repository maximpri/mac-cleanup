# Code of conduct

Mac Cleanup is committed to a welcoming, safe, and respectful community.

## Expected behavior

- Be considerate, constructive, and specific.
- Respect different backgrounds, experience levels, and viewpoints.
- Focus criticism on ideas and code rather than people.
- Protect other people's privacy, especially when discussing filesystem data,
  logs, or screenshots.
- Accept maintainer decisions about project scope and safety requirements.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, deliberate disruption, and publishing another person's private
information are not tolerated.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub
profile. Reports will be reviewed promptly and handled as confidentially as
practical. Maintainers may edit or remove contributions, restrict
participation, or ban contributors whose behavior violates this policy.

This policy applies in project repositories, issue trackers, reviews,
discussions, and other spaces where someone represents the project.
