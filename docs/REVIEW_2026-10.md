# Code and open-source readiness review — 2026-10-02

Reviewed the `8d623a6` baseline, focusing on terminal lifecycle, demo-script
filesystem safety, installed-app licensing, dependency policy, and the public
source-release path. This is a focused review, not an exhaustive audit of every
cleanup rule or a certification of legal compliance.

## Findings and changes

## Refactoring boundaries

The terminal refactor changes session ownership and restoration, not cleanup
eligibility or confirmation rules. Unit tests inject terminal operations;
the live smoke test exercises the built application's actual PTY lifecycle and
asserts that the original terminal modes are restored on successful exit. CI
runs that smoke test on disposable fixtures after building the release binary.
The demo tests use small disposable files and stub only expensive or
macOS-specific seed, clone, and date commands.

## GPL and distribution

The project already used **GPL-3.0-or-later**; this review preserves that choice
and the full, unmodified GPLv3 text. It adds the project copyright notice,
installed-app access to license terms, and dependency-review instructions.

The release workflow remains source-only. Before offering binaries, maintainers
must follow [RELEASING.md](../RELEASING.md): preserve applicable dependency
notices and offer exact corresponding source and build instructions. The
dependency policy is not a replacement for collecting those notices.

The Homebrew tap remains a separate setup task. No release tag, binary release,
tap repository, signing identity, or notarization credential is created by this
change. Private vulnerability reporting is enabled on the existing public
upstream repository.
